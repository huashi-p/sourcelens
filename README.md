# SourceLens

SourceLens 是一个多网址交叉验证 Agent。它读取用户提供的公开网页，
提取正文和相关段落，比较不同来源的共同观点、冲突和资料限制，
并生成带真实来源链接的 Markdown 报告。

Week 9 的输入、输出和冻结范围见 [MVP.md](MVP.md)。

## 项目状态

当前为 Week 9 MVP 本地版本，已完成并发抓取、URL 安全校验、
正文提取、相关段落筛选、交叉验证、来源校验和 Markdown 报告。

当前版本只分析用户提供的 2–5 个公开网址，不自动搜索互联网。

## 当前能力

- 同时读取 2–5 个公开网址，最多并发 2 个请求。
- 单个来源超时、被限流或返回错误时，不影响其他来源。
- 只允许 HTTP 和 HTTPS，以及默认端口、80 或 443。
- 拒绝账号密码 URL、内网 IP 和解析到内网地址的域名。
- 手动检查每次重定向，最多 3 次。
- 原始响应最多 2 MB，每个来源提取正文最多 20000 字符。
- 对超时、网络错误、429 和 5xx 最多重试 2 次。
- 从网页正文中选择最多 8 个相关段落，每段最多 800 字符。
- 对相关段落和重复内容进行筛选。
- 报告区分共同观点、冲突信息、未回答问题和资料限制。
- 至少两个来源成功时才生成交叉验证报告。
- 共同观点至少引用两个不同来源。
- 本地校验模型返回的来源编号、真实 URL 和证据原文。
- 校验失败时拒绝写出 Markdown 报告。
- 成功生成 `latest-report.md`。

## 处理流程

```text
输入研究问题和 2–5 个公开网址
→ 校验 URL、DNS 和端口
→ 处理重定向
→ 并发抓取网页
→ 提取正文和相关段落
→ 比较多个来源
→ 校验来源编号和真实 URL
→ 输出 JSON 和 Markdown 报告
```

每个结论包含：

- `text`：结论内容。
- `evidence_quote`：支持结论的原文。
- `source_ids`：模型使用的内部来源编号。
- `source_urls`：本地代码根据真实成功来源转换出的网址。

共同观点至少需要两个不同来源；其他结论至少需要一个来源。

## 报告结构

```text
common_points   多个来源共同支持的观点
conflicts       不同来源互相矛盾的信息
unanswered      现有资料没有回答的问题
limitations     网页内容不完整或资料覆盖有限等限制
successful_sources  成功读取的来源
failed_sources      失败来源及错误原因
```

## 安装

```powershell
cd D:\code\sourcelens
D:\code\sourcelens\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

复制 `.env.example` 为 `.env`，并填写自己的模型 Key。

```env
DEEPSEEK_API_KEY=你的密钥
```

不要提交 `.env`，也不要把 API Key 发到聊天、截图或 GitHub。

## 运行

```powershell
cd D:\code\sourcelens
D:\code\sourcelens\.venv\Scripts\python.exe compare_demo.py
```

演示脚本会真实请求配置中的公开网址，并调用 `.env` 中配置的模型。

运行成功后：

- 终端输出来源抓取信息和结构化 JSON。
- Markdown 报告写入 `latest-report.md`。
- 部分来源失败时，其余来源仍可生成报告。
- 报告未通过本地来源校验时，不写出 Markdown 文件。

## 安全规则

- 只接受公开 HTTP 和 HTTPS 网址。
- 不接受账号密码形式的 URL。
- 不接受内网、回环、链路本地和云元数据地址。
- 每次重定向后重新校验目标地址。
- 原始响应限制为 2 MB。
- 模型返回的 `source_ids` 必须对应成功抓取的真实来源。
- 模型不能自行提供一个任意 URL 作为真实来源。

## 当前限制

- 不执行 JavaScript，因此动态页面可能提取不到正文。
- URL 校验与实际连接会分别解析 DNS，仍存在 DNS 重绑定风险。
- 不使用向量检索，交叉验证质量依赖模型和页面正文质量。
- 报告只比较用户提供的来源，不自动搜索全网。
- 每个来源正文最多保留 20000 字符，长页面仍可能遗漏内容。
- 相关段落使用轻量关键词规则，不是完整的语义检索。
- 模型的结论分类和资料限制仍可能不准确，需要人工查看来源原文。
- 登录页面、验证码和私有内网页面不在当前范围内。
- 当前没有域名、HTTPS 和正式公网部署。
