# SourceLens Week 7 Mock 验证

## 验证目标

- 多个 mock URL 并发请求
- 最多 2 个请求同时执行
- 单个来源超时不终止整体任务
- 输出成功、失败和耗时

## 当前结果

- 成功来源数：2
- 失败来源数：2
- 实测总耗时：约 467 ms
- 串行执行预计耗时：约 950 ms
- 最大并发数：2
- 单来源超时：0.35 秒

失败来源分别覆盖无效页面和超时。一个来源失败不会终止整体任务，
成功来源仍会正常返回。

当前数字来自确定性 mock 请求，只能说明并发限制、超时和部分失败
处理的机制有效，不代表真实网页下载耗时。
